# G Gayathri — Portfolio Website

Hey there! Thanks for stopping by the repo for my personal portfolio.

I didn't want a site that felt like a static resume pasted onto a screen—I wanted something interactive, clean, and genuinely fun to explore. Built in a **Royal Blue, Black, and White** palette, this site brings together my AI/ML engineering and Python Full-Stack work in one place.

## What Makes It Fun to Explore

- **White / Black Mode Toggle** — Switch effortlessly between crisp daylight white and sleek midnight black.
- **`⌘K` Command Palette** — Hit `Ctrl+K` (or `Cmd+K`) to search projects, skills, or jump straight to any section.
- **Live Telemetry Card** — Preview key project architectures right from the hero section.
- **Engineering Ecosystem Map** — Click or hover over any skill node to see how it connects to my shipped work.
- **Interactive Project Case Studies** — Filter by category and open detailed breakdowns for each project.
- **Portfolio AI Concierge** — Ask quick questions about my skills, education, or projects.
- **Quick Resume Viewer & Vibe Check** — Preview my resume in one click, or hit the Vibe Check button for a little confetti.
